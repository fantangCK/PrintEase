# 文件转换处理说明

## 概述

PrintEase 后端提供了文件自动转换为 PDF、提取页数、计算页面覆盖率的功能。

---

## 前置条件

### 1. 安装 LibreOffice

文件转换（Word/Excel/PPT → PDF）需要 LibreOffice。

**Windows:**
- 下载并安装：https://www.libreoffice.org/download/download/
- 安装后确保 `soffice` 命令可以在命令行运行

**验证安装：**
```bash
soffice --version
```

---

## 技术栈

| 功能 | 库 | 说明 |
|------|-----|------|
| 文件转换 | LibreOffice | Word/Excel/PPT → PDF |
| PDF 页数提取 | pdf-parse | Node.js 专用 PDF 解析库 |
| 异步处理 | 原生 Promise | 无需 Redis，简单异步 |

---

## 工作流程

### 文件上传 → 自动转换

```
1. 用户上传文件
   ↓
2. 保存文件到数据库（conversionStatus = pending）
   ↓
3. 立即异步启动转换（不阻塞用户）
   ↓
4. 转换过程：
   - 如果是 PDF，直接处理
   - 如果是其他格式，用 LibreOffice 转 PDF
   ↓
5. 提取 PDF 页数
   ↓
6. 计算页面覆盖率（当前简化为默认值）
   ↓
7. 更新数据库（conversionStatus = completed / failed）
```

---

## 数据库字段（File 实体）

| 字段 | 类型 | 说明 |
|------|------|------|
| conversionStatus | enum | pending / converting / completed / failed |
| convertedPdfPath | string | 转换后的 PDF 文件路径 |
| totalPages | int | PDF 总页数 |
| blackWhiteCoverage | decimal | 黑白覆盖率（%） |
| colorCoverage | decimal | 彩色覆盖率（%） |
| conversionError | text | 转换失败错误信息 |
| convertedAt | datetime | 转换完成时间 |

---

## 转换状态说明

| 状态 | 说明 |
|------|------|
| pending | 等待转换（刚上传） |
| converting | 正在转换中 |
| completed | 转换成功 |
| failed | 转换失败 |

---

## API 接口

### 1. 上传文件
```
POST /files/upload
```
- 上传后立即返回，转换在后台异步执行
- 返回结果包含 `conversionStatus` 字段

### 2. 获取文件信息
```
GET /files/:id
```
- 返回完整的转换信息：
  - conversionStatus
  - totalPages
  - convertedPdfPath
  - blackWhiteCoverage
  - colorCoverage
  - conversionError

### 3. 获取文件列表
```
GET /files
```
- 列表中的每个文件都包含 `conversionStatus`

## 前端使用建议

### 轮询转换状态

文件上传后，前端可以轮询 `/files/:id` 接口查看转换进度：

```javascript
// 示例伪代码
async function waitForConversion(fileId) {
  let file = await getFileInfo(fileId)
  
  while (file.conversionStatus === 'pending' || file.conversionStatus === 'converting') {
    await sleep(1000) // 等待 1 秒
    file = await getFileInfo(fileId)
  }
  
  if (file.conversionStatus === 'completed') {
    console.log('转换成功！页数：', file.totalPages)
  } else {
    console.error('转换失败：', file.conversionError)
  }
}
```

## 常见问题

### Q: 为什么不用 Redis？
A: 为了简化部署，改用简单的异步处理。对于中小项目完全够用。

### Q: 页面覆盖率计算为什么是默认值？
A: 完整的覆盖率计算需要渲染 PDF 每页为图片，依赖较多，暂时简化为固定值（黑白 5%，彩色 0%）。

### Q: LibreOffice 转换失败怎么办？
A: 检查：
1. LibreOffice 是否正确安装
2. `soffice` 命令是否可用
3. 查看日志中的错误信息

### Q: 转换大文件会不会超时？
A: LibreOffice 转换设置了 60 秒超时。超大文件可能需要调整。
