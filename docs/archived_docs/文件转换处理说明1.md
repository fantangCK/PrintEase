# 文件转换处理说明

## 概述

本系统实现了用户上传文件到 PDF 格式的自动转换功能，支持多种文件格式，并提供 PDF 页数提取和页面覆盖率计算，用于后续打印价格计算。

## 前置条件

### 安装 LibreOffice

文件转换依赖 LibreOffice，需要在服务器上安装：

#### Windows
1. 下载并安装 LibreOffice：https://www.libreoffice.org/download/download/
2. 将 LibreOffice 的安装目录（如 `C:\Program Files\LibreOffice\program`）添加到系统环境变量 PATH 中
3. 验证安装：在命令行执行 `soffice --version`

#### Linux (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install libreoffice -y
```

#### macOS
```bash
brew install --cask libreoffice
```

## 技术栈

- **LibreOffice**: 用于将 Word、Excel、PPT 等格式转换为 PDF
- **pdf-parse**: 用于提取 PDF 页数
- **TypeORM**: 数据库操作
- **NestJS**: 后端框架

## 工作流程

1. 用户上传文件
2. 文件信息保存到数据库（`conversionStatus = PENDING`）
3. 触发文件转换处理
4. 根据文件类型判断是否需要转换：
   - PDF 文件：直接处理页数和覆盖率
   - 非 PDF 文件：使用 LibreOffice 转换为 PDF
5. 提取 PDF 页数
6. 计算页面覆盖率（黑白、彩色）
7. 更新数据库记录（`conversionStatus = COMPLETED` 或 `FAILED`）

## 数据库字段

### File 实体扩展字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `totalPages` | int | PDF 总页数 |
| `conversionStatus` | varchar(20) | 转换状态：pending/converting/completed/failed |
| `convertedPdfPath` | varchar(255) | 转换后的 PDF 文件路径 |
| `blackWhiteCoverage` | decimal(5,2) | 黑白覆盖率（%） |
| `colorCoverage` | decimal(5,2) | 彩色覆盖率（%） |
| `conversionError` | text | 转换错误信息 |
| `convertedAt` | datetime | 转换完成时间 |

## 转换状态说明

| 状态 | 值 | 说明 |
|------|----|------|
| 待处理 | `pending` | 文件已上传，等待转换 |
| 转换中 | `converting` | 正在进行文件转换 |
| 已完成 | `completed` | 转换成功完成 |
| 失败 | `failed` | 转换失败 |

## 核心服务说明

### ConversionService

核心转换服务，负责：
- 协调整个转换流程
- 调用 LibreOffice 进行文件转换
- 调用 PdfProcessorService 处理 PDF
- 更新数据库状态

主要方法：
- `processFileConversion(fileId: number)` - 处理文件转换

### PdfProcessorService

PDF 处理服务，负责：
- 提取 PDF 页数
- 计算页面覆盖率（待完善）

主要方法：
- `getPageCount(pdfPath: string)` - 获取 PDF 页数
- `calculatePageCoverage(pdfPath: string)` - 计算页面覆盖率

## 支持的文件格式

理论上 LibreOffice 支持的所有格式，包括：

- **文档格式**: .doc, .docx, .odt, .txt, .rtf
- **表格格式**: .xls, .xlsx, .ods, .csv
- **演示格式**: .ppt, .pptx, .odp
- **PDF 格式**: .pdf

## 使用示例

### 集成转换功能

```typescript
// 在文件上传成功后调用转换
@Injectable()
export class FileService {
  constructor(
    @InjectRepository(File)
    private fileRepository: Repository<File>,
    private conversionService: ConversionService,
  ) {}

  async uploadFile(file: Express.Multer.File, userId: number) {
    // 1. 保存文件信息到数据库
    const fileRecord = this.fileRepository.create({
      userId,
      fileName: file.originalname,
      filePath: file.path,
      fileSize: file.size,
      fileType: file.mimetype,
      fileExt: file.originalname.split('.').pop(),
    });
    await this.fileRepository.save(fileRecord);

    // 2. 异步触发转换
    this.conversionService.processFileConversion(fileRecord.id);

    return fileRecord;
  }
}
```

## 常见问题

### 1. LibreOffice 命令找不到

**问题**: 执行 `soffice` 命令报错 "command not found"

**解决方案**:
- 确认 LibreOffice 已正确安装
- 将 LibreOffice 的安装目录添加到 PATH 环境变量
- Windows: 通常在 `C:\Program Files\LibreOffice\program`
- 重启终端或 IDE 使环境变量生效

### 2. 转换超时

**问题**: 大文件转换超时

**解决方案**:
- 当前超时时间设置为 60 秒
- 可在 `conversion.service.ts` 的 `convertWithLibreOffice` 方法中调整 `timeout` 参数

### 3. PDF 生成失败

**问题**: LibreOffice 执行成功但 PDF 文件不存在

**可能原因**:
- 文件格式不支持
- 文件损坏
- 输出目录权限问题

**排查步骤**:
1. 检查 `conversionError` 字段的错误信息
2. 手动执行 LibreOffice 命令测试转换
3. 检查文件是否可以正常打开

### 4. 覆盖率计算不准确

**说明**: 当前覆盖率计算功能暂时返回默认值，需要后续完善。

**后续计划**:
- 使用 pdf.js 或其他 PDF 渲染库
- 将 PDF 页面渲染为图片
- 分析像素颜色分布计算覆盖率
