## 二、快速开始

### 2.1 克隆项目并初始化子模块

```bash
# 1. 克隆主项目
git clone <your-main-repo-url> PrintEase
cd PrintEase

# 2. 初始化并更新所有子模块
git submodule update --init --recursive

# 或者使用提供的脚本
# Windows
.\scripts\init-submodules.ps1

# Linux/macOS
./scripts/init-submodules.sh
```

### 2.2 启动开发环境 (Docker)

**所有服务都容器化，复用 mpay 的 MySQL。**

```bash
# 1. 先启动 mpay (包含 MySQL)
cd mpay
docker-compose up -d
cd ..

# 2. 在 mpay-mysql 中创建 print_ease 数据库
docker exec -i mpay-mysql mysql -uroot -pmpay7890 -e "CREATE DATABASE IF NOT EXISTS print_ease CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 3. 启动 PrintEase 服务
# Windows
.\scripts\start-dev.ps1

# Linux/macOS
./scripts/start-dev.sh

# 或直接使用 docker-compose
docker-compose -f docker/docker-compose.dev.yml up -d
```

### 2.3 访问服务

| 服务 | 地址 | 说明 |
|------|------|------|
| 印易后台 API | http://localhost:3000 | NestJS 后端 |
| 管理后台 | http://localhost:5173 | Vue3 + Element Plus |
| mpay 支付 | http://localhost:80 | 已有支付系统 |
| MySQL | localhost:3306 | 复用 mpay-mysql (root/mpay7890) |

### 2.4 云印调度 (本地 Python 客户端)

云印调度**不容器化**，直接运行在用户本地电脑上：

```bash
cd PrintEase-dispatch

# 1. 创建虚拟环境 (推荐)
python -m venv venv

# 2. 激活虚拟环境
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置
# 复制 configs/config.yaml.example 为 configs/config.yaml
# 并修改 backend_url 为 http://localhost:3000

# 5. 运行
python src/main.py
```

云印调度启动后会显示 Tkinter GUI 界面，包含：
- 任务列表
- 打印机状态
- 日志输出
- 设置选项

## 三、项目结构与 Git Submodules

### 3.1 子模块说明

| 子模块 | 路径 | 说明 |
|--------|------|------|
| PrintEase-dispatch | PrintEase-dispatch/ | 云印调度 (Python + Tkinter) |
| PrintEase-backend | PrintEase-backend/ | 印易后台 (NestJS) |
| PrintEase-uniapp | PrintEase-uniapp/ | 印易小程序 (UniApp) |
| PrintEase-admin | PrintEase-admin/ | 管理后台 (Vue3 + Element Plus) |
| mpay | mpay/ | 印易支付 (已有) |

### 3.2 常用 Git Submodule 命令

```bash
# 拉取所有子模块最新代码
git submodule foreach git pull origin main

# 提交子模块修改
# 1. 先进入子模块目录提交
cd PrintEase-backend
git add .
git commit -m "feat: xxx"
git push

# 2. 然后在主项目更新子模块引用
cd ..
git add PrintEase-backend
git commit -m "update: PrintEase-backend"
```

## 七、常见问题

### Q1: 子模块拉取失败？
**A:** 检查子模块仓库地址是否正确，确保有访问权限。

### Q2: Docker 容器启动失败？
**A:** 
1. 检查端口 3000、5173、3306、8080 是否被占用
2. 查看日志：`docker-compose -f docker/docker-compose.dev.yml logs`
3. 确保 Docker 服务已启动

### Q3: 云印调度无法连接后端？
**A:** 检查 `PrintEase-dispatch/configs/config.yaml` 中的 `backend_url` 配置是否正确。

### Q4: 数据库连接失败？
**A:** 
1. 确认 MySQL 容器已启动
2. 检查环境变量中的数据库配置
3. 默认账号：root / root123456

### Q5: 如何更新子模块？
**A:** 
```bash
# 拉取所有子模块最新代码
git submodule foreach git pull origin main

# 或者只更新特定子模块
cd PrintEase-backend
git pull origin main
```
