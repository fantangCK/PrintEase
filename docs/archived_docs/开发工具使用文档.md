# 开发工具使用文档

## 概述

`dev_tools` 文件夹提供了一套完整的开发和测试工具，用于帮助开发者快速集成和测试 mpay 支付系统。所有工具仅在开发环境可用，生产环境请禁用。

## 访问控制

### 配置文件：`config.php`

开发工具的访问控制由 `config.php` 管理，主要配置项：

```php
// 开发环境开关 - 设置为 true 可以访问开发工具
define('DEV_TOOLS_ENABLED', true);

// 允许访问的 IP 列表（可选）
define('DEV_TOOLS_ALLOWED_IPS', [
    '127.0.0.1',
    '::1',
    '172.19.0.1',
    '172.18.0.1',
]);
```

### 生产环境安全建议

在生产环境部署前，请确保：
1. 设置 `DEV_TOOLS_ENABLED = false`
2. 或者删除整个 `dev_tools` 文件夹
3. 配置 Nginx 规则禁止访问该目录

### 4. 支付通知验证页面 - `notify_test.php`

**访问地址**：`http://localhost/dev_tools/notify_test.php`（通过 pay_notify_test.php 跳转）

**功能说明**：
- 验证支付通知的签名是否正确
- 显示接收到的所有参数
- 展示完整的签名验证过程
- 验证成功后返回 "success"

**验证流程**：

1. **接收参数**：获取 GET 请求的所有参数
2. **提取签名**：从参数中提取 sign 字段
3. **计算签名**：
   - 移除 sign 和 sign_type 参数
   - 按 ASCII 码排序参数
   - 拼接成 URL 键值对格式
   - 拼接商户密钥
   - MD5 加密
4. **比较验证**：比对接收到的签名和计算出的签名
5. **返回结果**：验证成功返回 "success"

#### MD5 签名算法

**签名步骤**：

1. 将所有参数按 **参数名 ASCII 码从小到大排序**（a-z）
2. **sign、sign_type、空值** 不参与签名
3. 拼接成 URL 键值对格式：`a=b&c=d&e=f`
4. 拼接商户密钥：`a=b&c=d&e=f + KEY`
5. MD5 加密，结果为 **小写**

**PHP 示例代码**：
```php
// 您的商户密钥
$key = 'your_secret_key';

// 1. 获取所有参数
$params = $_GET;

// 2. 验证签名
$sign = $params['sign'] ?? '';
unset($params['sign']);
unset($params['sign_type']);

// 按 ASCII 排序
ksort($params);
$signStr = '';
foreach ($params as $k => $v) {
    if ($v != '') {
        $signStr .= $k . '=' . $v . '&';
    }
}
$signStr = substr($signStr, 0, -1);
$signStr .= $key;
$calculatedSign = md5($signStr);

// 3. 验证签名
if ($sign !== $calculatedSign) {
    die('sign error');
}

// 4. 验证支付状态
if ($_GET['trade_status'] !== 'TRADE_SUCCESS') {
    die('status error');
}

// 5. 处理您的业务逻辑
$out_trade_no = $_GET['out_trade_no'];
$money = $_GET['money'];

// TODO: 更新您的数据库订单状态
// TODO: 发货、增加余额等操作

// 6. 返回 success（非常重要！必须是小写）
echo 'success';
```

#### 安全建议

- ✅ **签名计算必须在服务器端进行**，不要在前端暴露商户密钥
- ✅ 收到通知后，一定要验证签名，防止伪造通知
- ✅ 验证订单金额是否与您的订单一致
- ✅ 处理通知时要做幂等性判断（防止重复处理）

## 注意事项

### Docker 环境特殊配置

在 Docker 环境中使用开发工具时，请注意：

1. **内部 API 调用**：
   - PHP 容器内使用服务名 `nginx` 访问 API
   - 例如：`http://nginx/mapi.php`

2. **外部访问地址**：
   - 从浏览器访问使用 `http://localhost`
   - 配置文件中 `app_host` 设置为 `http://localhost`

3. **通知地址**：
   - 内部通知使用 `http://nginx/dev_tools/notify_receiver.php`
   - 外部测试使用 `http://localhost/dev_tools/notify_receiver.php`

### 数据库配置

开发工具默认连接的数据库配置：
- 主机：`mysql`（Docker 服务名）
- 数据库：`mpay`
- 用户名：`mpay`
- 密码：`mpay7890`

如需修改，请编辑各工具文件中的数据库连接配置。

### 生产环境部署

生产环境部署前，请务必：

1. 禁用开发工具：
   ```php
   define('DEV_TOOLS_ENABLED', false);
   ```

2. 或删除 dev_tools 文件夹：
   ```bash
   rm -rf www/public/dev_tools
   ```

3. 配置 Nginx 禁止访问：
   ```nginx
   location /dev_tools/ {
       deny all;
   }
   ```

## 常见问题

### Q: 开发工具无法访问？
A: 请检查 `config.php` 中的 `DEV_TOOLS_ENABLED` 是否设置为 `true`，以及您的 IP 是否在允许列表中。

### Q: 创建订单失败？
A: 请检查：
1. 数据库是否正常连接
2. 商户ID和密钥是否正确
3. API 地址是否可访问

### Q: 收不到支付通知？
A: 请检查：
1. notify_url 是否正确配置
2. 服务器是否能访问到 notify_url
3. 通知接收页面是否返回 "success"

### Q: 签名验证失败？
A: 请检查：
1. 商户密钥是否正确
2. 参数排序是否正确
3. 是否排除了 sign 和 sign_type 参数
4. 空值是否参与了签名
