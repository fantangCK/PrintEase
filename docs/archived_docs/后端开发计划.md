# PrintEase 印易 - 后端开发计划

## 一、项目概述

**项目名称**：PrintEase 印易 - 自助打印服务系统

**技术栈**：
- 后端框架：NestJS 10+
- 开发语言：TypeScript 5+
- 数据库：MySQL 8.0
- ORM：TypeORM
- 认证：JWT + 微信小程序登录
- 容器化：Docker + Docker Compose

## 三、开发阶段划分

### 阶段 1：项目初始化与基础配置
**目标**：搭建完整的项目骨架，配置好开发环境

| 任务 | 详细内容 | 预估时间 |
|------|----------|----------|
| 1.1 创建数据库 | 使用 SQL 创建 `print_ease` 数据库 | 15min |
| 1.2 初始化 NestJS 项目 | 使用 Nest CLI 创建项目，安装基础依赖 | 30min |
| 1.3 配置 TypeScript & ESLint | 配置严格模式、代码规范 | 30min |
| 1.4 配置环境变量 | 创建 .env.example、.env，配置 ConfigModule | 30min |
| 1.5 配置数据库连接 | TypeORM 配置、MySQL 连接 | 45min |
| 1.6 创建目录结构 | 按架构设计创建 modules、common、config、database 等目录 | 30min |
| 1.7 配置 Docker | 创建 Dockerfile、Dockerfile.dev | 30min |

**阶段 1 总时间**：约 3.5 小时

## 六、开发规范

### 代码规范
- 使用 TypeScript 严格模式 (`strict: true`)
- 遵循 NestJS 最佳实践
- ESLint + Prettier 代码格式化
- Git 提交规范：`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`

### 目录结构
```

├── src/
│   ├── modules/              # 功能模块
│   │   ├── auth/
│   │   ├── user/
│   │   ├── file/
│   │   ├── order/
│   │   ├── dispatch/
│   │   └── payment/

│   │   ├── filters/
```
