# 第一部分：需求规格说明书

## 1. 项目概述

### 1.1 项目背景
随着移动互联网的普及，自助服务需求日益增长。本项目旨在开发一款自助打印小程序，用户可以通过手机上传文件，选择打印参数，提交订单后，系统自动派单给云印调度服务，云印调度自动下载文件并调用系统打印API完成打印，实现便捷、高效的自动化打印服务。

### 1.2 项目目标
- 提供便捷的文件上传和打印服务
- 支持多种文件格式（PDF、Word、Excel、图片等）
- 提供清晰的订单管理和查询功能
- 支持云印调度服务自动化打印
- 跨平台云印调度（支持Linux、Windows及多架构）
- 确保系统安全稳定运行
- 使用配置文件管理可变地址，方便修改
- 遵循SOLID设计原则，保证代码可维护性和扩展性
- API认证使用微信提供的官方机制

## 2. 核心模块详细设计

### 2.1 云印调度 (PrintEase Dispatch)

#### 2.1.1 模块职责
- 节点注册与心跳保活
- 轮询获取待打印任务
- 下载打印文件
- 调用系统打印API执行打印
- 打印状态实时上报
- GUI界面展示（任务列表、打印机状态、日志等）

#### 2.1.2 技术实现

**为什么选择 Python：**
- 打印调度是 **IO 密集型**任务（轮询、下载、打印API调用），Python 性能完全足够
- Tkinter 是 Python 内置 GUI 库，**无需额外依赖**，轻量高效
- Python 跨平台打印库生态丰富
- 开发效率高，快速迭代

**跨平台打印方案：**

| 操作系统 | 打印方案 | 库/工具 |
|----------|----------|---------|
| Windows | Win32 Print API | `pywin32` / `win32print` |
| Linux | CUPS | `pycups` / `lp` 命令 (待办) |
| macOS | CUPS | `pycups` / `lp` 命令 |

# 第三部分：外卖平台化改造 - 完整开发计划

## 1. 项目概述

### 1.1 改造目标
将 PrintEase 印易项目从简单的自助打印系统改造为类似外卖平台的完整生态系统，包含：
- **用户端**：下单、支付、查看订单
- **商户端**：接单、打印、上传完成照片
- **管理端**：订单管理、用户管理、商户管理、价格管理、公告管理

### 1.2 核心功能（重点）

#### 🎯 必须优先实现的核心功能

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **1. 多角色身份体系** | P0 | 用户、商户、管理员三种身份，通过 role 字段区分 |
| **2. 管理员和商户认证** | P0 | 管理员和商户使用密钥/权限系统认证 |
| **3. 我的页面增加管理员入口** | P0 | 我的页面增加"管理员设置"按钮 |
| **4. 公告移至管理员页面** | P0 | 公告从首页隐藏，只在管理员页面可见和管理 |
| **5. 商户接单功能** | P0 | 商户可以抢单/接单 |
| **6. 管理员接单+管理订单** | P0 | 管理员不仅可以接单，还可以管理所有订单 |
| **7. 打印完成照片上传** | P0 | 商户打印完成后，必须上传1-3张照片证明完成 |
| **8. 价格体系独立化** | P1 | 所有打印价格单独配置管理 |
| **9. 文件转换和覆盖率计算** | P1 | 上传文件自动转PDF，自动计算页面覆盖率 |

#### 角色权限说明

| 角色 | 权限范围 |
|------|---------|
| **普通用户 (role=0)** | 下单、支付、查看自己的订单、确认收货 |
| **商户 (role=1)** | 接单、打印、上传完成照片、查看自己的订单、管理店铺 |
| **管理员 (role=2)** | **所有权限**：<br>✅ 接单（同商户）<br>✅ 管理所有订单<br>✅ 管理用户<br>✅ 管理商户<br>✅ 管理价格<br>✅ 管理公告<br>✅ 数据统计 |
