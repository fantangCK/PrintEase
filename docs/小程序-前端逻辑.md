# PrintEase 印易 - 小程序前端逻辑文档

## 一、下单流程

### 1.1 流程图
```
选择文件 (微信/本地) -> 上传文件 -> 转换预览 -> 设置参数 (份数/颜色/纸张) -> 确认订单 -> 支付 -> 等待接单 -> 打印中 -> 已完成
```

### 1.2 关键页面
- `pages/upload/index`: 文件上传。
- `pages/order/create`: 订单确认与参数设置。
- `pages/order/detail`: 订单详情与状态查看。
- `pages/merchant/*`: 商户端页面 (新增)。
- `pages/merchant/grab-orders`: 商户接单大厅。
- `pages/merchant/my-orders`: 商户订单管理。
- `pages/merchant/settings`: 商户设置页面。

## 二、支付处理逻辑

### 2.1 支付调用
- **API**: `createPayment(orderId)`
- **逻辑**: 
  - 调用后端接口获取 `payUrl`。
  - 跳转至 WebView 加载支付页面。
  - 支付完成后轮询订单状态或用户手动点击"刷新状态"。

### 2.2 支付回调处理
- 后端通过 `/orders/pay/callback` 接收支付结果。
- 订单状态自动更新为"待接单"，进入商户抢单队列。
- 前端通过轮询或手动刷新查看订单状态变化。

## 三、商户端逻辑

### 3.1 入口
- 在底部导航栏增加"商户"标签页。
- 商户通过独立的登录页面进行登录。

### 3.2 功能
- **接单大厅** (`pages/merchant/grab-orders`): 展示待接单的订单，商户可以抢单。
  - 提供"我的栋"/"全部"筛选选项
  - 支持按楼栋筛选订单
  - 显示订单基本信息（订单号、时间、位置、页数、金额）
  - 提供"接单"按钮，点击后弹出确认框
- **订单管理** (`pages/merchant/my-orders`): 查看已接单的任务，管理订单状态。
- **状态更新**: 提供"开始打印"、"完成打印"等操作按钮。
- **商户设置** (`pages/merchant/settings`): 商户信息管理。

## 四、文件预览
- **逻辑**: 
  - 优先使用后端返回的 `convertedPdfPath`。
  - 使用 `uni.downloadFile` + `uni.openDocument` 实现预览。
  - 下载链接需包含 `/api` 前缀且为 HTTP/HTTPS 协议。

## 五、注意事项
1. **Token 管理**: 登录后将 Token 存入 Storage，请求拦截器自动添加 Header。商户使用独立的 `merchantToken`。
2. **文件大小**: 限制上传文件大小 (推荐 50MB)，超大文件提示用户。
3. **轮询优化**: 避免过高频率轮询订单状态，建议使用 WebSocket 或长轮询 (待实现)。
4. **商户身份**: 商户端操作使用独立的身份验证，通过 `merchantToken` 区分用户和商户权限。
