# PrintEase 印易 - 小程序前端逻辑文档

## 一、下单流程

### 1.1 流程图
```
选择文件 (微信/本地) -> 上传文件 -> 转换预览 -> 设置参数 (份数/颜色) -> 确认订单 -> 支付 -> 等待接单
```

### 1.2 关键页面
- `pages/upload/index`: 文件上传。
- `pages/order/create`: 订单确认与参数设置。
- `pages/order/detail`: 订单详情与状态查看。
- `pages/merchant/*`: 商户端页面 (新增)。

## 二、支付处理逻辑

### 2.1 支付调用
- **API**: `createPayment(orderId)`
- **逻辑**: 
  - 调用后端接口获取 `payUrl`。
  - 跳转至 WebView 或展示支付二维码。
  - 支付完成后轮询订单状态或用户手动点击"我已支付"。

### 2.2 支付复用前端表现
- 前端无需特殊处理，后端会自动判断是返回旧链接还是新链接。
- 用户体验一致，减少重复扫码困扰。

## 三、商户端逻辑 (规划)

### 3.1 入口
- 在"我的"页面，根据用户 `role` 字段判断。
- `role=1` (商户) 或 `role=2` (管理员) 显示"商户中心"入口。

### 3.2 功能
- **抢单大厅**: 轮询/WebSocket 获取待接单订单。
- **订单管理**: 查看已接单任务，上传完成照片。
- **状态更新**: 点击"开始打印"、"完成打印"。

## 四、文件预览
- **逻辑**: 
  - 优先使用后端返回的 `convertedPdfPath`。
  - 使用 `uni.downloadFile` + `uni.openDocument` 实现预览。
  - 下载链接需包含 `/api` 前缀且为 HTTP/HTTPS 协议。

## 五、注意事项
1. **Token 管理**: 登录后将 Token 存入 Storage，请求拦截器自动添加 Header。
2. **文件大小**: 限制上传文件大小 (推荐 50MB)，超大文件提示用户。
3. **轮询优化**: 避免过高频率轮询订单状态，建议使用 WebSocket 或长轮询 (待实现)。
