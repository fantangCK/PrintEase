# PrintEase 印易 - 项目环境与工具文档

## 一、开发环境配置

### 1.1 基础依赖
- **Node.js**: 18+
- **MySQL**: 8.0+
- **Python**: 3.10+ (用于辅助脚本)
- **Docker & Compose**: 推荐用于快速启动服务

### 1.2 快速启动 (Docker)
1. **Clone 项目**: `git clone ...`
2. **初始化子模块**: `git submodule update --init --recursive`
3. **启动服务**:
   ```bash
   # Windows
   .\scripts\start-dev.ps1
   # Linux/Mac
   ./scripts/start-dev.sh
   ```
4. **访问**:
   - 后端 API: `http://localhost:3000`
   - 管理后台: `http://localhost:5173`
   - 支付测试: `http://localhost:8080` (mpay)

### 1.3 本地开发 (非 Docker)
- **Backend**: `cd PrintEase-backend && npm install && npm run start:dev`
- **Admin**: `cd PrintEase-admin && npm install && npm run dev`
- **UniApp**: 使用 HBuilderX 打开 `PrintEase-uniapp` 运行。
  - 用户端: 编译为微信小程序
  - 商户端: 通过商户登录入口进入商户功能
- **Database**: 需手动安装 MySQL 并导入 `database/migrations`。
- **Dispatch**: `cd PrintEase-dispatch && conda env create -f environment.yml && conda activate printease-dispatch && python src/main.py`

## 二、开发工具箱

### 2.1 支付测试工具 (`dev_tools`)
位于 `mpay/www/dev_tools/`，仅开发环境开启。
- **创建订单测试**: 模拟小程序下单，生成支付链接。
- **支付通知测试**: 模拟 mpay 异步回调，验证后端签名逻辑。
- **日志查看**: 查看 `notify_receiver.php` 接收到的回调日志。

### 2.2 商户端开发工具
- **商户测试账号**: 可在管理后台创建测试商户账号用于功能测试。
- **接单模拟**: 商户可在"接单大厅"测试接单、打印、完成等流程。
- **订单状态流转**: 测试订单从"待接单"到"打印中"再到"已完成"的状态变化。

### 2.3 数据库管理
- 推荐使用 DBeaver 或 Navicat 连接 MySQL。
- 默认账号: `root` / `mpay7890` (Docker 环境)。

### 2.4 接口调试
- 推荐使用 Postman 或 Apifox。
- 导入 `API文档` 中的接口定义进行调试。

## 三、常见问题
1. **Docker 端口冲突**: 检查 3000, 3306, 8080 端口是否被占用。
2. **依赖安装失败**: 尝试配置 npm 淘宝镜像或使用 yarn/pnpm。
3. **支付回调不通**: 确保 `notify_url` 是公网可访问地址或 Docker 容器间可访问地址 (如 `http://host.docker.internal:...`)。
4. **商户功能无法访问**: 确保商户已通过认证并在系统中注册，使用正确的商户登录接口。
5. **接单大厅无订单**: 检查是否有待接单的订单（状态为1），并确认商户有权限查看相应楼栋的订单。
