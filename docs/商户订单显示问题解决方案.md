# 商户端订单显示问题解决方案

## 问题描述

商户端"我的订单"页面无法正常显示订单，显示"暂无订单"，但接单大厅正常工作。

## 问题分析

### 1. 前端iOS兼容性问题

**问题原因：**
- 使用了可选链操作符 `?.`，该语法在iOS Safari内核上不兼容
- 日期格式 `yyyy-mm-dd` 在iOS上存在兼容性问题

**影响范围：**
- 商户端接单大厅 (`src/pages/merchant/grab-orders.vue`)
- 商户端我的订单 (`src/pages/merchant/my-orders.vue`)
- 订单详情页面 (`src/pages/order/detail.vue`)
- 用户首页 (`src/pages/user/index.vue`)
- 订单首页 (`src/pages/order/index.vue`)

### 2. API响应格式处理

**问题原因：**
- 不同API返回的响应格式不一致
- 有些返回直接数组，有些返回包含 `list` 字段的对象

**影响范围：**
- 商户端我的订单页面的响应解析

## 解决方案

### 方案一：前端代码修改（已实施）

#### 1.3 完善响应格式处理

**商户端我的订单页面响应处理：**
```typescript
async function loadTasks() {
  try {
    loading.value = true
    const res: any = await getMerchantTasksGrouped()
    
    // 处理不同的响应格式
    if (res && res.list && Array.isArray(res.list)) {
        // 包含list字段的对象格式
        groupedTasks.value = res.list
    } else if (res && Array.isArray(res)) {
        // 直接是数组格式
        groupedTasks.value = res
    } else {
        // 其他格式
        groupedTasks.value = []
    }
  } catch (e) {
    console.error('Error loading tasks:', e)
  } finally {
    loading.value = false
  }
}
```
