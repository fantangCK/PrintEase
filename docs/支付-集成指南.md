# PrintEase 印易 - 支付集成与修复指南

## 一、支付系统概述
本项目使用 mpay (聚合支付系统) 进行支付处理。支持微信、支付宝等多种渠道。

## 二、核心业务逻辑

### 2.1 支付流程
1. **创建订单**: 用户在小程序下单。
2. **发起支付**: 后端调用 mpay 接口 (`/mapi.php`) 创建支付订单。
3. **获取链接**: mpay 返回支付链接/二维码。
4. **用户支付**: 用户扫码支付。
5. **异步通知**: mpay 回调后端 `notify_url`。
6. **状态更新**: 后端验证签名，更新订单状态为 `PENDING_PRINT` (待打印/待接单)。

### 2.2 支付订单复用机制 (Payment Reuse)
为避免用户重复点击支付导致创建大量无效支付订单，系统实现了**支付订单复用**。
- **背景**: 用户在支付页面可能多次点击"立即支付"，或者取消支付后重新支付。
- **逻辑**: 
  1. 检查 `orders` 表中是否存在有效的 `mpay_trade_no` 和 `mpay_pay_url`。
  2. 检查支付链接是否仍然有效（通常有效期为30分钟）。
  3. **未过期**: 直接返回已存在的 `mpay_pay_url`，**不调用 mpay 接口**。
  4. **已过期或不存在**: 调用 mpay 接口创建新支付订单，更新 `orders` 表。

## 三、关键问题修复 (Fix Logic)

### 3.1 微信支付金额提取失败修复
**问题描述**: 
微信支付回调消息格式发生变化，导致原有的正则无法正确提取金额，特别是包含千分位分隔符 (如 `1,200.00`) 的金额。

**修复逻辑**:
在 `mpay/www/extend/payclient/WxPay.php` 中更新正则表达式，并增加对千分位逗号的处理。

**代码变更**:
```php
// 旧逻辑 (可能失败)
// $patt = '/￥(\d+\.\d{2})/';

// 新逻辑 (修复后)
// 1. 匹配金额，支持千分位 (如 1,200.00)
$regex = '/(\d{1,3}(?:,\d{3})*(?:\.\d{1,2})?)(?=元)/';

if (preg_match($regex, $msg, $matches)) {
    // 2. 移除逗号，确保 floatval 正确解析
    $moneyStr = str_replace(',', '', $matches[1]);
    $money = floatval($moneyStr);
}
```

### 3.2 支付宝二维码显示 Null 修复
**问题描述**: 
PC 端访问支付宝支付页面 (`console.html`) 时，二维码无法生成，显示为 null。原因是前端 JS 解析 URL 参数逻辑有误。

**修复逻辑**:
简化 `mpay/www/view/pay/console.html` 中的 JS 逻辑，直接使用后端传递的 `payCode` 变量，不再从 URL 中二次解析。

**代码变更**:
```javascript
// 旧逻辑 (错误)
// var url = getQueryString("url"); 
// if(!url) url = "<?php echo $payurl; ?>";

// 新逻辑 (修复后)
// 直接使用后端注入的变量，确保准确
var qrCodeUrl = "<?php echo $payCode; ?>"; 
new QRCode(document.getElementById("qrcode"), qrCodeUrl);
```

### 3.3 404 错误与权限放宽修复
**问题描述**: 
商户或管理员在查看订单详情时遇到 404 错误，原因是后端过严的权限校验 (只允许订单所有者查看)。

**修复逻辑**:
在 `OrderController.getOrderDetail` 中增加权限判断，如果是商户或管理员角色，允许查看任意订单。

**逻辑伪代码**:
```typescript
async getOrderDetail(@Param('id') id: string, @Request() req: any) {
  console.log(`Getting order detail for id: ${id}, user type: ${req.user?.type}, user id: ${req.user?.userId}`);
  let order;
  // 如果是商户或管理员，允许查看任意订单
  if (req.user.type === 'merchant' || req.user.type === 'admin') {
    // 允许管理员查看所有订单，不需要传 userId
    if (req.user.type === 'admin') {
      order = await this.orderService.findByIdForMerchant(id, null);
    } else {
      order = await this.orderService.findByIdForMerchant(id, req.user.userId);
    }
  } else {
    // 普通用户只能看自己的订单
    order = await this.orderService.findById(id, req.user.userId);
  }
  
  return {
    code: 0,
    message: 'success',
    data: { /* 订单详情 */ },
  };
}
```
