## 二、核心模块详细设计

### 2.1 云印调度 (PrintEase Dispatch)

#### 2.1.1 模块职责

- 节点注册与心跳保活
- 轮询获取待打印任务
- 下载打印文件
- 调用系统打印API执行打印
- 打印状态实时上报
- GUI界面展示（任务列表、打印机状态、日志等）

#### 2.1.2 技术实现

**为什么选择 Python：**
- 打印调度是 **IO 密集型**任务（轮询、下载、打印API调用），Python 性能完全足够
- Tkinter 是 Python 内置 GUI 库，**无需额外依赖**，轻量高效
- Python 跨平台打印库生态丰富
- 开发效率高，快速迭代

**跨平台打印方案：**

| 操作系统 | 打印方案 | 库/工具 |
|----------|----------|---------|
| Windows | Win32 Print API | `pywin32` / `win32print` |
| Linux | CUPS | `pycups` / `lp` 命令 (待办) |
| macOS | CUPS | `pycups` / `lp` 命令 |

**GUI 框架：** Tkinter (Python内置、跨平台、轻量、无需额外安装)

**核心流程：**

```
1. 启动 → 显示GUI → 节点注册
   ↓
2. 心跳保活 (每30秒) + GUI更新节点状态
   ↓
3. 任务轮询 (每5秒) + GUI更新任务列表
   ↓
4. 认领任务 → 下载文件 → GUI显示下载进度
   ↓
5. 调用系统打印API → GUI显示打印进度
   ↓
6. 上报打印状态 (打印中/完成/失败) + GUI更新
```

## 九、Docker 容器化部署

### 9.1 容器化范围

| 模块 | 是否容器化 | 说明 |
|------|-----------|------|
| PrintEase-backend | ✅ 是 | NestJS 服务 |
| PrintEase-admin | ✅ 是 | Vue3 SPA (Nginx 托管) |
| PrintEase-uniapp | ✅ 是 | 可选 (开发阶段可不用) |
| **PrintEase-dispatch** | ❌ **否** | 本地 Python 客户端，直接运行在用户电脑上 |
| mpay | ✅ 是 | 已有 Dockerfile |
| MySQL | ✅ (复用 mpay 的 MySQL) | 不再单独启动，复用 mpay-mysql |
| Redis | ⏳ 待办 | 后续迭代再添加 |

### 9.3 MySQL 复用说明

复用 mpay 的 MySQL 配置：
- 主机: mpay-mysql (Docker 网络内)
- 端口: 3306
- Root 密码: mpay7890
- 我们可以在同一个 Docker 网络中访问，创建独立的数据库 print_ease

### 9.2 docker-compose.yml (开发环境)

注意：mpay 有自己的 docker-compose.yml，我们通过网络连接复用它的 MySQL。

```yaml
version: '3.8'

services:
  print-ease-backend:
    build:
      context: ./PrintEase-backend
      dockerfile: Dockerfile.dev
    container_name: printease-backend
    environment:
      NODE_ENV: development
      DB_HOST: mpay-mysql
      DB_PORT: 3306
      DB_USERNAME: root
      DB_PASSWORD: mpay7890
      DB_DATABASE: print_ease
    ports:
      - "3000:3000"
    volumes:
      - ./PrintEase-backend:/app
      - /app/node_modules
      - ./uploads:/app/uploads
      - ./logs:/app/logs
    networks:
      - printease-network
      - mpay_mpay-network
    command: npm run start:dev

  print-ease-admin:
    build:
      context: ./PrintEase-admin
      dockerfile: Dockerfile.dev
    container_name: printease-admin
    ports:
      - "5173:5173"
    volumes:
      - ./PrintEase-admin:/app
      - /app/node_modules
    networks:
      - printease-network
    command: npm run dev -- --host

networks:
  printease-network:
    driver: bridge
  mpay_mpay-network:
    external: true
```

### 9.5 启动顺序

1. 先启动 mpay (包含 MySQL)
2. 再启动 PrintEase 服务

```bash
# 1. 启动 mpay
cd mpay
docker-compose up -d

# 2. 创建 print_ease 数据库 (在 mpay-mysql 中)
docker exec -i mpay-mysql mysql -uroot -pmpay7890 -e "CREATE DATABASE IF NOT EXISTS print_ease CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 3. 回到主项目，启动 PrintEase 服务
cd ..
docker-compose -f docker/docker-compose.dev.yml up -d
```

### 10.2 快速开始

#### 1. 克隆项目并初始化子模块

```bash
# 克隆主项目
git clone <main-repo-url> PrintEase
cd PrintEase

# 初始化并更新所有子模块
git submodule update --init --recursive

# 或者使用提供的脚本
# Windows
.\scripts\init-submodules.ps1

# Linux/macOS
./scripts/init-submodules.sh
```

#### 2. 启动开发环境 (Docker)

```bash
# Windows
.\scripts\start-dev.ps1

# Linux/macOS
./scripts/start-dev.sh

# 或直接使用 docker-compose
docker-compose -f docker/docker-compose.dev.yml up -d
```

#### 3. 访问服务

| 服务 | 地址 |
|------|------|
| 印易后台 API | http://localhost:3000 |
| 管理后台 | http://localhost:5173 |
| mpay 支付 | http://localhost:8080 |
| phpMyAdmin (可选) | http://localhost:8081 |

#### 4. 云印调度 (本地运行，非容器化)

云印调度需要访问本地打印机和 GUI，建议本地运行：

```bash
cd PrintEase-dispatch

# 创建虚拟环境 (推荐)
python -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行
python src/main.py
```

### 10.4 常见问题

**Q: 子模块拉取失败？**
A: 检查子模块仓库地址是否正确，确保有访问权限。

**Q: Docker 容器启动失败？**
A: 检查端口是否被占用，查看日志：`docker-compose logs`

**Q: 云印调度无法连接后端？**
A: 检查 `configs/config.yaml` 中的 backend_url 配置是否正确。

| POST | /api/dispatch/task/:id/status | 上报状态 |

**订单API：**

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/orders | 创建订单 |
| GET | /api/orders | 订单列表 |
| GET | /api/orders/:id | 订单详情 |
| PUT | /api/orders/:id/status | 更新订单状态 |

**文件API：**

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/files/upload | 上传文件 |
| GET | /api/files/:id | 获取文件信息 |

## 三、数据流转设计

### 3.1 完整打印流程

```
用户 (小程序)                    印易后台                    云印调度                  系统打印
    │                             │                             │                      │
    │  1. 上传文件               │                             │                      │
    ├────────────────────────────>│                             │                      │
    │                             │  保存文件                   │                      │
    │<────────────────────────────┤                             │                      │
    │  返回文件ID                 │                             │                      │
    │                             │                             │                      │
    │  2. 提交订单(含打印参数)    │                             │                      │
    ├────────────────────────────>│                             │                      │
    │                             │  创建订单                   │                      │
    │                             │  创建打印任务(状态:待分配)   │                      │
    │<────────────────────────────┤                             │                      │
    │  返回订单号                 │                             │                      │
    │                             │                             │                      │
    │                             │  3. 任务轮询                │                      │
    │                             │<────────────────────────────┤                      │
    │                             │  返回待分配任务              │                      │
    │                             ├────────────────────────────>│                      │
    │                             │                             │  4. 认领任务            │
    │                             │<────────────────────────────┤                      │
    │                             │  更新任务状态:已分配        │                      │
    │                             ├────────────────────────────>│                      │
    │                             │                             │                      │
    │                             │  5. 下载文件                │                      │
    │                             │<────────────────────────────┤                      │
    │                             │  返回文件                   │                      │
    │                             ├────────────────────────────>│                      │
    │                             │                             │                      │
    │                             │                             │  6. 调用打印API         │
    │                             │                             ├─────────────────────>│
    │                             │                             │                      │  执行打印
    │                             │                             │<─────────────────────┤
    │                             │                             │  打印完成              │
    │                             │                             │                      │
    │                             │  7. 上报打印状态            │                      │
    │                             │<────────────────────────────┤                      │
    │                             │  更新任务/订单状态          │                      │
    │                             │  通知用户                   │                      │
    │<────────────────────────────┤                             │                      │
    │  订单完成通知               │                             │                      │
```

### 3.2 订单状态流转

```
待支付 ──(支付成功)──> 待打印 ──(分配给节点)──> 打印中 ──(打印完成)──> 已完成
   │                        │                        │
   │                        │                        │
(支付失败/取消)         (用户取消)              (打印失败)──> 失败重试
   │                        │                        │
   ▼                        ▼                        ▼
  已取消                   已取消                  已失败
```

### 3.3 打印任务状态流转

```
待分配 ──(节点认领)──> 已分配 ──(开始打印)──> 打印中 ──(打印成功)──> 已完成
                                                         │
                                                         │
                                                    (打印失败)──> 已失败
```

services:
  mysql:
    image: mysql:8.0
    container_name: printease-mysql
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: print_ease
    ports:
      - "3306:3306"
    volumes:
      - mysql-data:/var/lib/mysql
    networks:
      - printease-network

  print-ease-backend:
    build: ./print-ease-backend
    container_name: printease-backend
    environment:
      NODE_ENV: production
      DB_HOST: mysql
      DB_PORT: 3306
      DB_USERNAME: root
      DB_PASSWORD: rootpassword
      DB_DATABASE: print_ease
    ports:
      - "3000:3000"
    depends_on:
      - mysql
    volumes:
      - ./uploads:/app/uploads
      - ./logs:/app/logs
    networks:
      - printease-network

  print-ease-admin:
    build: ./print-ease-admin
    container_name: printease-admin
    ports:
      - "5173:80"
    depends_on:
      - print-ease-backend
    networks:
      - printease-network

  mpay:
    build: ./mpay
    container_name: printease-mpay
    ports:
      - "8080:80"
    networks:
      - printease-network

      - "80:80"

      - ./nginx/conf.d:/etc/nginx/conf.d

      - print-ease-backend

volumes:
