# PrintEase 印易 - 下单流程文档

## 一、概述

本文档详细介绍 PrintEase 小程序的完整下单流程，包括文件上传、转换、价格计算、订单创建等环节。

---

## 二、完整下单流程

### 2.1 流程总览

```
用户进入小程序
    ↓
选择文件上传
    ↓
文件格式检查
    ↓
如需转换 → 发送转换请求 → 等待转换完成
    ↓
无需转换（PDF）
    ↓
进入订单创建页面
    ↓
选择打印参数（份数、颜色、单双面等）
    ↓
实时计算价格
    ↓
填写备注（可选）
    ↓
确认创建订单
    ↓
跳转支付页面
    ↓
支付完成 → 订单状态变为「待打印」
```

---

### 2.2 文件上传流程

#### 2.2.1 支持的文件格式
- **可直接打印**：PDF
- **需转换**：DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, JPG, PNG 等

#### 2.2.2 文件上传步骤
1. 用户在上传页面选择本地文件
2. 前端调用文件上传接口 `/api/files/upload`
3. 后端接收文件并保存到服务器
4. 后端返回文件信息（包括文件 ID、文件名、文件大小、页数等）
5. 前端检查文件类型，如果不是 PDF 则显示转换按钮

#### 2.2.3 文件信息字段
```typescript
{
  id: number;              // 文件 ID
  fileName: string;        // 原始文件名
  filePath: string;        // 文件存储路径
  fileSize: number;        // 文件大小（字节）
  fileType: string;        // MIME 类型
  fileExt: string;         // 文件扩展名
  totalPages?: number;     // 总页数（PDF/DOC等）
  convertedPdfPath?: string; // 转换后 PDF 路径
}
```

---

### 2.3 文件转换流程

#### 2.3.1 转换触发条件
- 文件扩展名不是 `.pdf`
- 用户点击「转换为 PDF」按钮

#### 2.3.2 转换步骤
1. 前端调用文件转换接口
2. 后端将转换任务加入队列
3. 前端轮询转换状态或通过 WebSocket 接收进度
4. 转换完成后，后端更新文件信息，添加 `convertedPdfPath` 字段
5. 前端显示转换完成，可继续下单

#### 2.3.3 转换状态
- `pending`: 等待转换
- `converting`: 转换中
- `completed`: 转换完成
- `failed`: 转换失败

---

### 2.4 价格计算逻辑

#### 2.4.1 价格配置（从数据库获取）
系统支持四种价格配置：
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| blackWhiteSingleSidedPrice | 黑白单面价格/页 | 0.1 元 |
| blackWhiteDoubleSidedPrice | 黑白双面价格/页 | 0.08 元 |
| colorSingleSidedPrice | 彩色单面价格/页 | 0.5 元 |
| colorDoubleSidedPrice | 彩色双面价格/页 | 0.4 元 |
| minPrice | 最低消费 | 0 元（无最低消费） |

**重要**：价格配置优先从数据库加载，不使用前端默认值。

#### 2.4.2 价格计算公式

1. **确定单价**：
   - 根据用户选择的 `color_type`（0=黑白，1=彩色）和 `double_sided`（0=单面，1=双面）确定单价
   - 黑白单面 → `blackWhiteSingleSidedPrice`
   - 黑白双面 → `blackWhiteDoubleSidedPrice`
   - 彩色单面 → `colorSingleSidedPrice`
   - 彩色双面 → `colorDoubleSidedPrice`

2. **计算页数**：
   - 如果是双面打印，页数向上取整到偶数
   - 例如：3 页双面 → 按 4 页计算

3. **计算总价**：
   ```
   总价 = 单价 × 页数 × 份数
   ```

4. **应用最低消费**（已取消）：
   - 如总价 < 最低消费，按最低消费计算
   - 目前最低消费设为 0，即无限制

#### 2.4.3 价格计算示例
- 文件：5 页
- 选择：黑白双面，2 份
- 计算：
  - 单价：0.08 元/页
  - 页数：5 页（双面，不满双数按双数计算 → 6 页）
  - 总价：0.08 × 6 × 2 = 0.96 元

### 2.5 订单创建流程

#### 2.5.1 订单创建接口
- **路径**：`POST /api/orders`
- **请求参数**：
```typescript
{
  fileIds: number[];         // 文件 ID 列表
  copies: number;             // 打印份数
  paperSize: string;          // 纸张大小（A4/A5/A3）
  colorType: number;          // 颜色类型（0=黑白，1=彩色）
  doubleSided: number;        // 双面打印（0=单面，1=双面）
  printQuality: string;       // 打印质量（draft/normal/high）
  remark?: string;            // 备注（可选）
  deliveryAddress?: string;   // 派送地址（可选）
  deliveryTime?: string;      // 派送时间（可选）
}
```

#### 2.5.2 订单创建步骤
1. 用户在订单创建页面填写打印参数
2. 前端实时计算并显示预估价格
3. 用户点击「确认下单」
4. 前端调用订单创建接口
5. 后端验证参数并创建订单
6. 后端返回订单信息（包括订单号、总金额等）
7. 前端跳转到支付页面

#### 2.5.3 订单状态
| 值 | 说明 |
|----|------|
| 0 | 待支付 |
| 1 | 待打印 |
| 2 | 打印中 |
| 3 | 已完成 |
| 4 | 已取消 |
| 5 | 已失败 |

---

### 2.6 文件预览功能

#### 2.6.1 预览时机
- **上传前**：已取消（避免不必要的预览）
- **转换后**：在订单创建页面和订单详情页面显示预览
- **订单列表**：在待打印订单页面显示预览

#### 2.6.2 预览文件选择
- 如果文件已转换（`convertedPdfPath` 存在），使用转换后的 PDF
- 否则使用原始文件（仅 PDF）

#### 2.6.3 预览方式
- 小程序中使用 `uni.openDocument` 打开 PDF 文件
- 需先通过 `uni.downloadFile` 下载文件到本地

## 三、前端页面流程

### 3.1 页面结构
1. **上传页面** (`pages/upload/index.vue`)：文件选择和上传
2. **转换页面** (`pages/upload/converting.vue`)：文件转换进度显示
3. **订单创建页面** (`pages/order/create.vue`)：打印参数选择和订单创建
4. **订单列表页面** (`pages/order/index.vue`)：订单列表展示
5. **订单详情页面** (`pages/order/detail.vue`)：订单详情展示

### 3.2 页面间跳转
```
上传页面 → 转换页面（如需转换）→ 订单创建页面 → 支付页面 → 订单详情页面
```
